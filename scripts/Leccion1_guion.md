## ¿Qué es la programación? [0:45 – 2:30]

*[Mostrar en pantalla: animación simple de pasos numerados]*

"Imagina que quieres enseñarle a un robot a hacer un sándwich. El robot no entiende 'hazme un sándwich'; necesita instrucciones precisas, paso a paso: primero toma el pan, luego pon la mantequilla, después agrega el relleno..."

"Eso mismo es la programación: darle instrucciones muy exactas y ordenadas a una computadora para que haga lo que tú quieres."

## ¿Qué es Java y por qué usarlo? [2:30 – 4:00]

*[Mostrar en pantalla: logos de aplicaciones conocidas hechas con Java]*

"Java es un lenguaje de programación creado en 1995. Hoy se usa en aplicaciones de Android, sistemas bancarios, juegos, y mucho más."

"Una de sus grandes ventajas: el mismo código funciona en cualquier computadora, sin importar si es Windows, Mac o Linux."

## Primer programa: ¡Hola, Mundo! [4:00 – 6:30]

*[Cambiar a pantalla del editor JDoodle. Tipear el código despacio, explicando cada línea.]*

"Abre el editor en línea que está en la descripción del video. Vamos a escribir nuestro primer programa juntos."

*[Escribir en el editor:]*
```java
public class Leccion1_HolaMundo {
    public static void main(String[] args) {
        System.out.println("¡Hola, Mundo!");
        System.out.println("Bienvenido al mundo de Java.");
    }
}
```

"Esta primera línea define la clase, que es como el contenedor de nuestro programa. La segunda línea es el punto de inicio: Java siempre empieza a ejecutar aquí. Y `System.out.println` es la instrucción para mostrar texto en pantalla."

*[Hacer clic en el botón Execute/Run]*

"¡Mira! Nuestro programa muestra los mensajes. Cambia el texto entre comillas por tu propio mensaje y vuelve a ejecutarlo."
